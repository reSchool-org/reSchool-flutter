# KMI Paste

KMI Paste - плагин для Obsidian, который импортирует текст с [kmi.aeza.net](https://kmi.aeza.net). По ссылке `obsidian://kmi` можно сохранить текст в новую заметку, дописать его в существующую или заменить её содержимое.

## Установка

1. Скачайте `main.js` и `manifest.json` из [последнего выпуска](../../releases/latest).
2. Скопируйте оба файла в папку `.obsidian/plugins/kmi-paste/` внутри хранилища Obsidian.
3. В настройках Obsidian откройте раздел сторонних плагинов и включите KMI Paste.

## Формат ссылки

```text
obsidian://kmi?file=<имя_файла>&path=<папка>&append=<true|false>&url=<ссылка_kmi>
```

| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| `file` | Да | Имя заметки. Расширение `.md` добавляется автоматически. |
| `url` | Да | Ссылка на текст на kmi.aeza.net. |
| `path` | Нет | Папка внутри хранилища, например `Notes/Work`. |
| `append` | Нет | `true` - дописать текст, `false` - заменить содержимое. По умолчанию `false`. Если заметка уже существует, оба действия требуют подтверждения. |

Примеры команд для macOS:

```bash
# импортировать текст в заметку mynote.md
open "obsidian://kmi?file=mynote&url=https://kmi.aeza.net/dJdFRy"

# дописать текст в заметку внутри папки Work/Logs
open "obsidian://kmi?file=log&path=Work/Logs&append=true&url=https://kmi.aeza.net/dJdFRy"
```

## Если заметка уже существует

Новую заметку плагин создаёт сразу. Если заметка с указанным именем уже есть, сначала открывается окно проверки. В нём показаны исходная ссылка, хранилище, целевая заметка, выбранное действие и загруженный текст. Зашифрованный текст расшифровывается перед показом.

По умолчанию предлагается сохранить текст как новую заметку: кнопка `Save as a new note` создаёт файл со свободным именем и суффиксом ` (import)`. Для дополнения или замены существующей заметки нужно нажать отдельную кнопку. Само открытие ссылки её не меняет.

Отмена, нажатие Escape, закрытие окна или отключение плагина оставляют заметку без изменений. Если заметку переместили или заменили, пока окно было открыто, обновление завершится ошибкой. В таком случае откройте ссылку заново и проверьте, куда будет сохранён текст.

## Сборка из исходников

Нужен Node.js 18 или новее. В папке плагина установите зависимости с версиями из файла фиксации и выполните сборку:

```bash
npm ci
npm run build
```

## Тесты

```bash
npm test
```

Команда сначала пересобирает плагин, затем проверяет собранный JavaScript с имитацией API Obsidian. Открывать хранилище или подключаться к сети для тестов не нужно.
